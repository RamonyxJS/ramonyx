# @ramonyx/core

Core contracts and primitives for Ramonyx: routes, config, cache, i18n, errors, and hooks.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/core
```
