# Internasionalisasi (i18n)

Routing locale + helper terjemahan **tanpa dependency** (ADR-0081): prefix `/<locale>`, `<html lang>`
(+`dir`), `hreflang` otomatis, locale di loader/action/prop halaman, dan penerjemah katalog
(interpolasi + plural + format `Intl`).

> Status: tersedia di `@ramonyx/core` (helper) + `@ramonyx/ssr` (routing) — dipakai playground
> (dogfood: `id` default + `/en/…`) dan diuji unit + e2e.

## Mengaktifkan routing locale

```ts
// src/app.ts
import { createPageRoutes } from "@ramonyx/ssr";

createPageRoutes({
  pages,
  renderer: createReactRenderer(),
  i18n: {
    locales: ["id", "en"],
    defaultLocale: "id",
    // prefixDefaultLocale: true,       // semua locale berprefix, termasuk default
    // directions: { ar: "rtl" },       // <html dir="rtl"> untuk locale tertentu
  },
});
```

Perilaku:

| Permintaan | Hasil |
| --- | --- |
| `/tentang` | Halaman dengan locale **default** (`id`) — tanpa prefix |
| `/en/tentang` | Halaman dengan locale `en` |
| `/id` · `/id/tentang` | **308** → `/` · `/tentang` (query dipertahankan) |
| `prefixDefaultLocale: true` | Kebalikannya: `/tentang` → 308 `/id/tentang` |

- `<html lang="…">` diisi locale aktif; `dir` diisi bila `directions[locale]` ada.
- `<head>` otomatis mendapat `<link rel="alternate" hreflang="…">` untuk setiap locale +
  `x-default` (URL absolut dari request).
- Locale tersedia di konteks loader/action (`{ locale }`) dan prop halaman (`PageProps.locale`);
  payload hydration ikut membawa locale (paritas server ↔ klien).
- **Cache data loader terpisah per locale** (key memuat locale) — halaman ber-`revalidate` tidak
  bocor antar bahasa.
- Rute API (`src/routes/api/**`) **tidak** terpengaruh prefix locale.

## Terjemahan

Katalog = objek bersarang (JSON-friendly), dimuat di loader dan diteruskan sebagai data halaman
(pola yang sama berlaku untuk katalog dari file/DB):

```tsx
// src/routes/page.tsx
import { createTranslator, type Messages } from "ramonyx";

const katalog: Record<string, Messages> = {
  id: { sapaan: "Halo {nama}!", item: { one: "{count} item", other: "{count} item" } },
  en: { sapaan: "Hello {nama}!", item: { one: "{count} item", other: "{count} items" } },
};

export async function loader({ locale }: { locale?: string }) {
  const aktif = locale ?? "id";
  const { t, formatNumber, formatDate } = createTranslator({
    locale: aktif,
    messages: katalog[aktif] ?? {},
    fallbackMessages: katalog.id,        // opsional
    // onMissing: (key) => console.warn("i18n:", key),   // dev
  });
  return {
    sapaan: t("sapaan", { nama: "Rina" }),          // "Halo Rina!"
    jumlah: t("item", { count: 3 }),                 // plural via Intl.PluralRules
    harga: formatNumber(1234.5),                     // Intl.NumberFormat
    tanggal: formatDate(new Date(), { dateStyle: "long" }), // Intl.DateTimeFormat
  };
}
```

- **Interpolasi**: `{nama}` diganti dari `params` (param yang hilang dibiarkan apa adanya).
- **Plural**: nilai objek (`one`/`other`/…) dipilih dengan `Intl.PluralRules` memakai `params.count`.
- **Fallback**: key tidak ada → `fallbackMessages` → `onMissing(key)` → key itu sendiri.
- Helper murni (edge-safe) — bisa dipakai juga di middleware dan komponen klien (kirim katalog
  lewat data loader).

## Language switcher

```tsx
import { localePath } from "ramonyx";

// dari halaman mana pun → tautan ke locale lain (prefix lama dilepas otomatis)
<a href={localePath(currentPath, "en", { locales: ["id", "en"], defaultLocale: "id" })}>English</a>
```

## Negosiasi `Accept-Language` (middleware)

Deteksi otomatis **tidak** dilakukan framework (eksplisit > ajaib, dan redirect otomatis
berisiko untuk SEO). Pola yang disarankan — middleware pre-routing + cookie:

```ts
import { negotiateLocale, localePath } from "ramonyx";
import { parseCookies, serializeCookie } from "@ramonyx/security";

const i18n = { locales: ["id", "en"], defaultLocale: "id" } as const;

export async function localeMiddleware(context, next) {
  const url = new URL(context.request.url);
  if (url.pathname !== "/") return next();
  const cookie = parseCookies(context.request.headers.get("cookie") ?? "")["locale"];
  const locale =
    cookie ?? negotiateLocale(context.request.headers.get("accept-language"), i18n);
  return new Response(null, {
    status: 302,
    headers: {
      location: localePath("/", locale, i18n),
      "set-cookie": serializeCookie("locale", locale, { path: "/", httpOnly: false, sameSite: "lax" }),
    },
  });
}
```

Pasang lewat `createHandler({ middleware: [...] })` (atau plugin — ADR-0067).

## Batasan (jujur)

- **Tanpa ICU MessageFormat** (hanya interpolasi `{nama}` + kategori plural `Intl`) — dependency
  pesan ICU tidak diambil (kebijakan ADR-0016); kandidat bila ada kebutuhan.
- **Tanpa deteksi/redirect otomatis** — pola middleware + cookie di atas; hreflang tetap otomatis.
- Katalog **bukan** dimuat framework dari file — aplikasi memuatnya (JSON/DB) dan meneruskan lewat
  data loader (bisa di-cache seperti data lain).
- Rute didaftarkan **per locale** (linear terhadap jumlah locale) — lokalisasi per-rute (mis.
  hanya sebagian halaman) belum didukung; pisahkan route group bila perlu.
- `hreflang` memakai path logis halaman (tanpa prefix) — untuk rute dinamis, alternatif mengikuti
  parameter yang sedang diminta.
