# @ramonyx/security

Security middleware and helpers for Ramonyx: headers, CSP, CSRF, rate limits, signed cookies, and SSRF guard.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/security
```
