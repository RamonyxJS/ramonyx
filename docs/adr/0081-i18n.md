# ADR-0081: i18n — Primitif di Core, Routing Locale di SSR, Tanpa Deteksi Otomatis

- Status: Accepted (2026-10-19)
- Tanggal: 2026-10-19
- Sumber: TODO `p3-i18n` ("Routing locale (prefix/domain), negosiasi Accept-Language, helper
  terjemahan server/client") — gap paritas terakhir vs Next.js/Nuxt/SvelteKit/Astro.

## Konteks

i18n adalah satu-satunya fitur `planned` yang tersisa. Kompetitor menyediakannya sebagai routing
bawaan (Next.js, Astro) atau modul (Nuxt i18n, SvelteKit paraglide). Ramonyx perlu: routing locale,
negosiasi bahasa, dan helper terjemahan yang bekerja di server **dan** klien — tanpa melanggar
kebijakan dependency (ADR-0016) dan tetap edge-safe.

## Keputusan

1. **Primitif di `@ramonyx/core`** (edge-safe, tanpa dependency — pola yang sama dengan
   `assets.ts`/`revalidate.ts`): `parseAcceptLanguage`, `negotiateLocale`, `localePath`,
   `createTranslator` (+ `Intl.PluralRules`/`NumberFormat`/`DateTimeFormat`). Tidak ada paket baru.
2. **Routing di `@ramonyx/ssr`** via `createPageRoutes({ i18n })`:
   - Rute didaftarkan **per locale dengan prefix literal** (`/en/tentang`), bukan segmen dinamis
     `[locale]` — menghindari ambiguitas precedence dengan rute statis/catch-all yang sudah ada
     (termasuk `[...notFound]` dan action POST).
   - **Default locale tanpa prefix** (default), `prefixDefaultLocale: true` untuk sebaliknya;
     permintaan ber-prefix default dinormalisasi **308** (query dipertahankan).
   - Locale diteruskan ke konteks loader/action (`{ locale }`), prop halaman (`PageProps.locale`),
     dan **payload hydration** (paritas klien).
   - Dokumen: `<html lang>` + `dir` (dari `directions`), dan `<link rel="alternate" hreflang>`
     otomatis untuk setiap locale + `x-default` (URL absolut dari request).
   - **Cache data loader memuat locale di key** — halaman ber-`revalidate` tidak bocor antar bahasa.
   - Rute API tidak terpengaruh.
3. **Tanpa deteksi/redirect otomatis**: negosiasi disediakan sebagai helper; aplikasi memakainya di
   middleware pre-routing + cookie (pola terdokumentasi di `docs/i18n.md`). Alasan: redirect
   otomatis berisiko (SEO, kejutan, cache) dan middleware-first adalah arsitektur yang sudah ada.
4. **Tanpa ICU MessageFormat**: interpolasi `{nama}` + kategori plural `Intl` saja — dependency ICU
   tidak diambil; kandidat bila ada kebutuhan nyata.

## Bukti

- `packages/core/test/i18n.test.ts` — negosiasi (q-value, prefix bahasa, fallback), `localePath`
  (default/prefix/ganti bahasa), penerjemah (dot-path, interpolasi, fallback, `onMissing`, plural,
  format `Intl`, locale tak dikenal aman).
- `packages/ssr/test/i18n.test.ts` — prefix/redirect 308 (+query), `prefixDefaultLocale`,
  `lang`/`dir`, hreflang + `x-default`, isolasi cache antar-locale, locale di action POST,
  catch-all per-locale, dan jalur tanpa i18n tetap normal.
- `apps/playground/e2e/i18n.spec.ts` — browser: `/` (id) vs `/en` (en), redirect `/id` → `/`,
  hydration (counter) di `/en`, 404 ter-lokalisasi.
- `docs/i18n.md` — panduan (termasuk pola middleware + cookie untuk negosiasi).

## Alternatif yang ditolak

- **Segmen dinamis `[locale]`**: bentrok precedence dengan rute statis/catch-all dan menambah
  kasus tepi (mis. `/users` vs `/[locale]/users`); prefix literal deterministik.
- **Redirect/deteksi otomatis dari `Accept-Language`**: perilaku tak terduga + risiko SEO/cache;
  middleware + cookie memberi kontrol penuh dan tetap satu baris helper.
- **Paket `@ramonyx/i18n` terpisah**: primitif ±200 baris tanpa dependency — memecah paket menambah
  permukaan rilis tanpa manfaat (BLUEPRINT §5 aturan 5); core sudah menjadi rumah primitif bersama.
- **ICU MessageFormat**: dependency + format parser; kebutuhan belum terbukti.

## Konsekuensi

- Aplikasi opt-in: tanpa `i18n`, perilaku persis seperti sebelumnya (test regresi tetap hijau).
- Tabel rute tumbuh linear terhadap jumlah locale (dicatat sebagai batasan).
- Kandidat lanjutan: lokalisasi per-rute (subset halaman), pemuat katalog dari file, ICU/format
  pesan lanjutan, deteksi domain-based (mis. `id.example.com`).
