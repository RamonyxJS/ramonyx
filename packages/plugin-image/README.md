# @ramonyx/plugin-image

Plugin varian gambar Ramonyx (resize + WebP/AVIF saat build) — sharp sebagai peer opsional.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/plugin-image
```

`sharp` is an optional peer dependency; install it in the app that enables image variants.
