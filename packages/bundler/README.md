# @ramonyx/bundler

Build pipeline for Ramonyx: Vite client bundles, edge builds, static prerender, and plugin hooks.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/bundler
```
