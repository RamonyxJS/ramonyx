# @ramonyx/adapter-runtime

Node.js runtime adapter for Ramonyx: HTTP host, static assets, compression, and ETag.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/adapter-runtime
```
