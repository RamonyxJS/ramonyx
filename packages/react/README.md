# @ramonyx/react

React renderer, client navigation, hydration, Link, Image, and asset helpers for Ramonyx.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/react
```

This package declares React 19 as a peer dependency. Install it alongside your app:

```bash
npm install @ramonyx/react react react-dom
```
