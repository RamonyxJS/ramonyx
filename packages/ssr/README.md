# @ramonyx/ssr

SSR page routes, streaming, metadata, SEO, caching, and static generation for Ramonyx.

Part of the Ramonyx framework. Requires Node.js 24 or newer and ESM.

## Install

```bash
npm install @ramonyx/ssr
```
